# Daan Roosenbrand

Portfolio van Daan Roosenbrand, saxofonist, klarinettist, dirigent en docent in Rotterdam.

## Netlify

| Instelling | Waarde |
| --- | --- |
| Build command | `npm run build` |
| Publish directory | `dist` |
| Node | 22 |

Foto's staan in `public/photos/`. `scripts/unpack-assets.mjs` pakt alleen uit als er een map `packed/` is; zonder die map doet de build niets extra.
